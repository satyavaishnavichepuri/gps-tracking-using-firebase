## Running the GPS Tracker Web App
(after ensuring that gps is connected and valid)

1. Open terminal/cmd and navigate to your project folder:
```
   cd Downloads\tbpmapping
```

2. Start the local server:
```
   python -m http.server 8080
```

3. Open Edge and go to:
```
   http://localhost:8080/gps_tracking_web.html
```

4. To stop the server, press `Ctrl+C` in the terminal.
